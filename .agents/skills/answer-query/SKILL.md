# Goal
Answer from accumulated knowledge, not from scratch.

# Steps
1. Start from `wiki/index.md`.
2. Read relevant topic, project, source, or answer pages.
3. Check `raw/` only if the wiki is insufficient.
4. Produce an answer grounded in the repo.
5. If the answer is reusable, save it to `wiki/answers/YYYY/`.

# Rules
- Prefer synthesis over repetition.
- Link to source summary pages when possible.
- Save durable analyses back into the wiki.
