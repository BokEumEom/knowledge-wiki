# knowledge-wiki

개인용 LLM 기반 지식 위키입니다.

이 저장소는 단순 문서 보관함이 아니라,
Claude Code와 Codex가 함께 읽고 정리하고 갱신하는
지속형 지식 저장소를 목표로 합니다.

## 구조
- `raw/`: 원본 자료 보관
- `wiki/`: 정리·요약·연결된 지식
- `schema/`: 위키 운영 규칙과 템플릿

## 기본 워크플로
1. 새 자료를 `raw/inbox/`에 넣는다
2. LLM이 자료를 읽고 `wiki/`에 요약/연결 페이지를 만든다
3. 질의 결과도 다시 `wiki/`에 축적한다
4. 주기적으로 링크, 충돌, 누락 내용을 점검한다
