# Wiki Conventions

## 원칙
- 원본은 `raw/`
- 정리된 지식은 `wiki/`
- 규칙은 `schema/`

## 페이지 작성 규칙
- 한 페이지는 하나의 주제를 중심으로 작성
- 짧은 요약 → 핵심 근거 → 관련 링크 순서 유지
- 가능한 한 관련 페이지를 상호 링크

## 필수 운영 파일
- `wiki/index.md`: 전체 페이지 안내
- `wiki/log.md`: ingest/query/lint 작업 기록
- `wiki/dashboards/open-questions.md`: 미해결 질문
- `wiki/dashboards/contradictions.md`: 상충 정보 정리
